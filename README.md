# California Tides

First working version of a GitHub Pages site using NOAA CO-OPS data and Plotly.

## Publish

1. Create a GitHub repository.
2. Upload `index.html` and this README.
3. Open **Settings → Pages**.
4. Select the main branch and `/ (root)`.
5. Save and open the generated GitHub Pages URL.

No build step or server is required.

## Included stations

9410230 La Jolla; 9410660 Los Angeles; 9410840 Santa Monica; 9411340 Santa Barbara; 9412110 Port San Luis; 9413450 Monterey; 9414290 San Francisco; 9415020 Point Reyes; 9416841 Arena Cove; 9418767 North Spit; 9419750 Crescent City.

## NOAA products

Predictions, water level, wind, air temperature, water temperature, and air pressure. The lower plots use NOAA's `recent` range (72 hours). Tide predictions and observed water levels use MLLW.
